`Anu-S`

Repository name:

`Anu-S.github.io`

## Publish on GitHub Pages

1. Sign in to GitHub.
2. Create a new **public** repository named `Anu-S.github.io`.
3. Upload the contents of this folder to the repository root.
4. Make sure `index.html` is in the repository root.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`.
8. Save.
9. GitHub Pages will publish the site at:

   `https://anu-s.github.io/`
